# Revature Notes and Projects

This repository collects notes, code examples, exercises, and small projects from Revature training. It covers backend, frontend, full-stack, database, cloud, and DevOps topics, with examples in several languages and frameworks.

## Contents

- **Week 1 - Java:** Language fundamentals, methods, operators, collections, exceptions, recursion, HTTP examples, JDBC, JUnit, and Spring examples, including XML-based configuration.
- **Week 2 - SQL:** Data types, data manipulation, composite keys, and database normalization.
- **Week 5 - Web fundamentals:** HTML and CSS exercises, JavaScript examples, object-oriented JavaScript, and todo-list projects, including a service-based version.
- **Week 6 - TypeScript:** TypeScript and object-oriented programming examples, plus a bundled todo-list project.
- **Week 7 - Angular:** Angular study notes.
- **Week 10 - Spring:** A Spring project with Gradle build files and source and test directories.
- **Week 11 - AWS and cloud:** Cloud fundamentals, Linux and Bash, CI/CD, Jenkins, Kubernetes, static analysis, and Docker notes and examples.
- **Week 12 - DevOps and Python:** DevOps study notes, serverless and Splunk topics, Python notes and beginner examples, and a Flask demo.

## Technologies

Examples and notes use Java, Spring, SQL/MySQL, HTML, CSS, JavaScript, TypeScript, Angular, Python, Flask, Docker, and related cloud and DevOps tools.

The material is arranged by training week so you can browse a topic alongside its examples and exercises.
